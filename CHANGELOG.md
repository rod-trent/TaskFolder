# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Configurable tray-menu item height from 24 to 64 pixels, applied to shortcut, category, profile, and management menu items.
- Custom tray-menu header text and an optional PNG, JPEG, BMP, GIF, or ICO logo.
- In-settings logo preview and removal control.

### Changed

- The tray menu is rebuilt after saving appearance settings so changes take effect immediately.
