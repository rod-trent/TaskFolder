# TaskFolder 1.3.0 — stable local release

Release date: 2026-10-26 (Asia/Seoul). Andrey accepted the current application
and explicitly requested its designation as a stable release. This promotes the
accepted `1.3.0-rc.4` implementation without adding runtime features or changing
user data formats.

## Included behavior

- The tray menu and desktop widget share the approved amber/orange Gates icon.
- The widget uses Explorer's rendered desktop layer and remains below ordinary
  application windows. Its appearance and working visibility were confirmed by
  the user after the host correction.
- Widget size is configurable from 50–200%. Hover menus hide after 200–2000 ms
  outside the widget and visible menu hierarchy (default 600 ms); re-entry
  cancels the countdown, and keyboard input keeps that session open.
- Nested menus inherit the main menu's effective font, including DPI changes,
  while retaining the configured item height. The user accepted this fix.
- Menu fades, outside-click dismissal and deferred Settings opening remain in
  place alongside the existing launcher, search, organization and recovery work.

## Compatibility and boundaries

State schema remains 2, operation journal schema 1 and configuration archive
schema 1. Release promotion does not migrate, reset or rewrite the user's data.

The packaged-app catalog provider remains disabled pending native Shell identity
proof. Clean-machine installer execution, physical mixed-DPI/lifecycle coverage,
Windows 10, full keyboard/IME and other native acceptance gaps described in the
[runbook](../usability-upgrade.md) remain separate from the user's stable-release
approval. Automated/hidden-window checks do not substitute for those scenarios.

Release-build verification completed:

- Release build: no warnings or errors.
- Core smoke suite: 1,267 assertions passed.

- Production widget/rendering fixture: 168 checks passed.
- Settings controls and form constructors passed in English/Russian and
  Light/Dark configurations, without showing desktop windows.

  extracted icon matches the shared ICO.

Artifacts are kept in `installer/stable-1.3.0/`:

- `TaskFolder-Setup-1.3.0-win-x64.exe`: self-contained Windows x64 installer.
- `TaskFolder-1.3.0-source.zip`: explicit source manifest snapshot, excluding

This source directory has no `.git` metadata. The manifest and source archive
freeze this local release; no Git commit, tag, push or remote/public release is
claimed. Earlier candidates and their installers are retained.
