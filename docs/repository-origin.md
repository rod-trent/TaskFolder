## Public fork and stable source

The public repository is [sorrowwind/TaskFolder](https://github.com/sorrowwind/TaskFolder).
It retains its GitHub fork relationship with the original project and its Git
history. The accepted 1.3.0 source was imported on top of the previous public
main commit `1c53be906e61c51e45b76b88781805ec96ca278b` without rewriting history.

The accepted runtime is preserved in commit
`0b46a389d23aca810ea831cbd8b289423f152c1d` and annotated tag `v1.3.0`.
That commit contains the 150 files from the frozen local source manifest plus
the original MIT `LICENSE` notice. The subsequent public documentation update
preserves the existing design metadata, excludes disposable build/QA output,
and describes this fork's provenance without changing application behavior.

The original local installer, source ZIP and checksum manifests predate Git
initialization. Those frozen artifacts remain unchanged. Their automated and
manual verification boundaries are recorded in [release notes](releases/1.3.0.md).
